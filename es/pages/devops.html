Herramientas libres y DevOps

Cadena de herramientas open source y fair-code · Proxmox VE · n8n · Snapshots · IaC · scripts

Nivel: Intermedio
La operación de la plataforma se apoya en una cadena de herramientas libres — software open source o fair-code / source-available cuando la licencia lo exige. El objetivo es la reproducibilidad (plantillas, clonación, snapshots), la reversibilidad (copias de seguridad, rollback) y la orquestación (n8n, scripts), sin dependencia de la nube. Los componentes cuya licencia no es una licencia open source aprobada por la OSI se señalan como tales.

  • Principios de IaC aplicados a la infraestructura virtual
  • Selección de herramientas libres / fair-code distinguiendo explícitamente las licencias
💻 Comandos DevOps de Proxmox
bash
# Backup VM avec snapshot
vzdump 100 --storage local-zfs --mode snapshot --compress zstd

# Clone depuis template
qm clone 9000 101 --name prod-ia-01 --full

# Snapshot avant modif
qm snapshot 101 pre-update-$(date +%Y%m%d) --description 'Avant mise à jour'

# Liste des snapshots
qm listsnapshot 101

# Rollback
qm rollback 101 pre-update-20250601
