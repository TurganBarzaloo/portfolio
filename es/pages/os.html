📋 Procedimiento de plantilla Ubuntu Server
bash
# Dans la VM Ubuntu (préparation template)
sudo apt update && sudo apt upgrade -y
sudo apt install -y qemu-guest-agent cloud-init

# Nettoyer
sudo cloud-init clean
sudo truncate -s 0 /etc/machine-id
sudo truncate -s 0 /var/lib/dbus/machine-id

# Éteindre proprement
sudo poweroff

# Dans Proxmox : convertir en template
qm template <VMID>
🎯 Competencias aplicadas
  • Administración avanzada de Linux (Debian/Ubuntu)
  • Creación de plantillas de VM reproducibles (Linux + Windows)
  • Sysprep de Windows para generalización
  • Despliegue y clonación rápida de VM
  • Instalación y configuración de CUDA Toolkit en Windows
  • Cloud-init para personalización automática en el arranque
