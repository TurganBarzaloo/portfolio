Outils libres & DevOps

Chaîne d'outillage open source & fair-code · Proxmox VE · n8n · Snapshots · IaC · scripts

Niveau : Intermédiaire
L'exploitation de la plateforme repose sur une chaîne d'outils libres — logiciels open source ou fair-code / source-available lorsque la licence l'impose. L'objectif est la reproductibilité (templates, clonage, snapshots), la réversibilité (sauvegardes, rollback) et l'orchestration (n8n, scripts), sans dépendance au cloud. Les composants dont la licence n'est pas une licence open source approuvée par l'OSI sont signalés comme tels.

💻 Commandes DevOps Proxmox
bash
# Backup VM avec snapshot
vzdump 100 --storage local-zfs --mode snapshot --compress zstd

# Clone depuis template
qm clone 9000 101 --name prod-ia-01 --full

# Snapshot avant modif
qm snapshot 101 pre-update-$(date +%Y%m%d) --description 'Avant mise à jour'

# Liste des snapshots
qm listsnapshot 101

# Rollback
qm rollback 101 pre-update-20250601
