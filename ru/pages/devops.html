Свободные инструменты и DevOps

Цепочка открытых и fair-code инструментов · Proxmox VE · n8n · Снимки · IaC · скрипты

Уровень: средний
Эксплуатация платформы опирается на цепочку свободных инструментов — программное обеспечение с открытым исходным кодом или fair-code / source-available, когда этого требует лицензия. Цель — воспроизводимость (шаблоны, клонирование, снимки), обратимость (резервное копирование, откат) и оркестрация (n8n, скрипты) без зависимости от облака. Компоненты, лицензия которых не является открытой лицензией, одобренной OSI, явно помечены как таковые.

🎯 Применённые компетенции
  • Переиспользуемые системные шаблоны (Ubuntu + Windows)
  • Клонирование ВМ для воспроизводимого развёртывания
  • Снимки перед каждым критическим изменением
  • Снимки Proxmox (vzdump) — пока не независимое резервное копирование
  • Оркестрация ИИ-workflow с помощью n8n
  • Принципы IaC, применённые к виртуальной инфраструктуре
  • Подбор свободных / fair-code инструментов с явным указанием лицензий
💻 DevOps-команды Proxmox
bash
# Backup VM avec snapshot
vzdump 100 --storage local-zfs --mode snapshot --compress zstd

# Clone depuis template
qm clone 9000 101 --name prod-ia-01 --full

# Snapshot avant modif
qm snapshot 101 pre-update-$(date +%Y%m%d) --description 'Avant mise à jour'

# Liste des snapshots
qm listsnapshot 101

# Rollback
qm rollback 101 pre-update-20250601
