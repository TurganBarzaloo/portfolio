VM302 — AI 开发工作站

Windows 11 · VSCodium · Python 3.13 · Node.js 24 LTS · DeepSeek Harness · 远程 GPU 推理

级别：高级
VM302 是一台专用于多语言开发和编程助手评估的 Windows 11 开发工作站。该机器没有本地 GPU：它消费单独托管的推理能力，从而将客户端工作站与计算服务分离。
✅ 已验证的基础与工具链
  • 虚拟化的 Windows 11 基础，无本地 GPU 加速器
  • VSCodium、Git 和 PowerShell 7 已通过功能测试验证
  • 访客身份、网络、访客代理和外设已重新验证
  • Python 3.13 — 包管理、虚拟环境、标准库离线测试
  • Node.js 24 LTS 和 npm — 运行本地 JavaScript 测试
  • DeepSeek Harness 采用固定的预览版本：已检查 lockfile、包完整性、依赖审计、安装脚本和原生模块
  • Harness 界面仅限本地机器，首个配置文件保持只读
🔎 远程推理与持久性
  • 首次使用 qwen3.6:35b 完成已验证的远程推理：控制提示准确返回 DSH_VM302_QWEN36_OK，未调用任何工具
  • 工作站重启后：版本、配置和会话历史均已保留
  • 新会话确认了预期响应和远程 GPU 加速
  • 推理服务的访问仅限专用网络，其 API 未直接发布到互联网
  • 自动化服务仅在健康状态层面检查，尚未声明由智能体消费
🧭 架构 — 客户端工作站，独立计算
开发工作站与推理服务之间的分离
VM302（Windows 11，无本地 GPU）
├── VSCodium · Git · PowerShell 7
├── Python 3.13 · Node.js 24 LTS
└── DeepSeek Harness（本地界面）
    └── 独立推理服务（专用网络）
        └── 远程 GPU 加速

工作站保持轻量且无 GPU：计算被委托给单独托管的推理服务，仅可在专用网络中访问。这种分离将开发工具与模型服务隔离开来。

🎯 展示的技能
  • 虚拟化 Windows 工作站的准备与验证
  • 多语言开发工具链的设计
  • 基于 Cordis 插件架构的智能体工具的受控安装
  • 将无 GPU 工作站与独立推理服务集成
  • 选择自由组件并分离专有依赖
  • 可复现测试与离线验证
  • 客户端工作站、推理服务与自动化的分离
🚧 限制与状态：
  • Rust 和 C/C++ 工具链仍属未来工作；
  • 助手比较以及由智能体执行自动化工作流仍有待完成；
  • DeepSeek Harness 仍以预览版本发布：不作为稳定组件呈现；
  • Windows 许可证和专有硬件组件使整体无法呈现为“100% 开源”。
